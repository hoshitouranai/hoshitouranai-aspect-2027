## Pre-Publication Notes

This package has been prepared for upload to GitHub. Public release has not yet been approved.

The `archive_source_candidates/` directory contains historical source code candidates dated October 28, 2026. These files do not constitute a complete regeneration system for the current `index.html`.

The original Swiss Ephemeris/Moshier astronomical calculation source code has not yet been located. Compliance with the source code availability requirements of the GNU AGPL for public distribution has therefore not been fully verified.

**Do not change the repository visibility to Public until the required checks are complete.**
